2.  Download  the Top.py file to your route directory
  
3. Name the file : top.py

 4. You will see a list of  stocks.  Change the symbols to any you want.  You must follow the same format. 
  
5.  Save the file and run this in PS from route directory ie:cd "C:\Users\yourname"
  run--     python.py
 
6. A  html file wil be created in the same directory that shows your  stocks.  The list updates by refreshing the file.
